# Phase XX engineering report template

- Phase / branch / commit / date:
- Owner / reviewer:
- Scope and acceptance criteria: table with PASS / FAIL / NOT_RUN and evidence.
- Inputs / provenance: source docs, fixture IDs, catalog schema/migration version.
- Design choices and alternatives: rationale and any revised decision records.
- Implementation inventory: files created/changed/removed, impact on originals and DB.
- Tests: exact commands, environments, results, warnings, failures, skipped and why.
- Outputs and measurements: counts, hashes, UI findings, API calls and costs (only if measured).
- Image-quality validation (when relevant): sample identities, comparisons, fidelity concerns, rejected artifacts.
- Security/privacy: secrets, GPS handling, export filtering, authorization.
- Limitations and blockers: unresolved, with severity and future owner.
- Reproduction/handoff: exact next actions and expected results.
- Acceptance recommendation: COMPLETE / INCOMPLETE, with supporting reasons; owner review status.
Never present a draft report as evidence for unperformed tests.
